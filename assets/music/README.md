# Music for the reels

Drop 10–15 calm, royalty-free tracks here (.mp3 / .m4a / .wav).
The robot picks one per video (always the same one for the same post), fades it in and out.
No tracks here = silent videos (still fine to post).

Only use music you have the right to use commercially (e.g. a paid licence, or tracks marked
free for commercial use). Never trending songs from TikTok/Instagram: the API cannot add them.
