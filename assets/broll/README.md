Nomme chaque clip avec le type de B-roll au début, puis un numéro :

| Tag dans Notion        | Nom du fichier            |
|------------------------|---------------------------|
| 🎥 Moi au clavier      | clavier-1.mp4, clavier-2.mp4 … |
| ☕ Café                 | cafe-1.mp4 …              |
| ✏️ Croquis papier       | croquis-1.mp4 …           |
| 📱 Téléphone + site     | telephone-1.mp4 …         |
| 💻 Écran / scroll       | ecran-1.mp4 …             |
| 🚋 Bruxelles            | bruxelles-1.mp4 …         |
| 🏪 Chez le client       | client-yaniswash-1.mp4 …  |
| 🌇 Fin de journée       | soir-1.mp4 …              |

Le robot prend tout seul un clip qui correspond aux tags « B-roll » du post.
S'il manque un type, le post passe en Error avec « Il manque le B-roll : … ».
Vertical 9:16, 5–15 s, caméra stable, lumière naturelle.
